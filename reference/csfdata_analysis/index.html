    csfdata_analysis

    Optional analysis add-ons for CSFData catalogues.

    Modules:

    Name Description
    catalogue_runner

    Parallel execution of standardized diagnostics over catalogue selections.
    choices

    Registered scientific choices used by standardized derived parameters.
    cli

    Command-line interface for CSFData analysis diagnostics.
    datamodel

    Pandas-oriented views of stored CSFData catalogue simulations.
    derived

    Safely import completed derived products between catalogues.
    diagnostics

    Standardized diagnostic definitions and automatic module registration.
    plotting

    Small plotting tools for standardized CSFData analysis tables.
    readers

    Readers that convert simulation output into standard analysis inputs.
    runner

    Run one standardized diagnostic over one imported simulation.
